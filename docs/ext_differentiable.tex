\section{A differentiable Voigt profile and Zeeman spectrum}
To fit parameters by gradients (with PyTorch), the spectrum must be a differentiable function of the field $B$, the temperature $T$ and the pressure $P$. \texttt{scipy.special.voigt\_profile} cannot be differentiated by PyTorch, and PyTorch has no complex error function, so \texttt{src/torch\_voigt.py} writes the Voigt profile with the Faddeeva function $w(z)=e^{-z^2}\operatorname{erfc}(-iz)$:
\begin{equation}
V(x;\sigma,\gamma)=\frac{\operatorname{Re}\,w(z)}{\sigma\sqrt{2\pi}},\quad z=\frac{x+i\gamma}{\sigma\sqrt2},\qquad
w(z)=\frac{2\,p(Z)}{(L-iz)^2}+\frac{1/\sqrt\pi}{L-iz},\quad Z=\frac{L+iz}{L-iz},\ L=\sqrt{N/\sqrt2},
\end{equation}
the rational approximation of Weideman~\cite{weideman} with $N=32$; $p$ is a polynomial whose coefficients come from one FFT, computed once. Evaluating $p$ by Horner's rule uses only $+,\times,\div$, so the same function runs on NumPy arrays and PyTorch tensors, and autograd gives the derivatives with respect to $x,\sigma,\gamma$. The widths follow from $T$ and $P$:
\begin{equation}
\sigma=\nu_0\sqrt{\frac{k_BT}{mc^2}},\qquad \gamma=\frac{A}{4\pi}+k_PP,
\end{equation}
with the pressure coefficient $k_P$ an input. Line positions and strengths come from the eigenvalues and eigenvectors of the Zeeman Hamiltonians (same model as Level~3); \texttt{zeeman\_spectrum} is then a sum of strength $\times$ Voigt. Derivatives of eigenvectors need non-degenerate levels, so the gradient with respect to $B$ is defined for $B>0$ only.

\paragraph{What is checked.} On the NumPy side the profile agrees with \texttt{scipy.special.voigt\_profile} to $4\times10^{-14}$ of the peak value for $\sigma\in[0.01,5]$, $\gamma\in[0,30]$, and the line list reproduces \texttt{transitions.zeeman\_lines} exactly. The PyTorch tests (agreement with NumPy, \texttt{gradcheck} on $\sigma,\gamma$, and gradients with respect to $B,T,P$ against central finite differences) are skipped when PyTorch is absent; they were written but not run in the environment where this report was prepared.
